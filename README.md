# Library Hub

Library Hub is a full stack web application developed to manage book records efficiently. The system allows users to add, update, delete, and search for books through a structured interface.

The frontend is built using React, providing a responsive and dynamic user experience. The backend is developed using Node.js and Express, where REST APIs are implemented to handle data operations. MongoDB is used as the database to store and manage book information.

The application is designed to ensure smooth interaction between frontend and backend, enabling users to perform operations in real time.

# Key Functionalities

- Add, update, delete, and view book records
- Search books based on user input
- REST API integration between frontend and backend
- Dynamic UI with real-time updates

# Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB

# Project Type

Full stack web application
